# Example files

Generate the reference stimuli into this directory with:

```bash
audiobench generate --output-dir examples/test_signals --sample-rate 48000 --duration 1
```

Audio files are generated by the tool and are not committed by default to keep the source repository small. For a quick comparison demonstration, copy any generated stimulus to `reference.wav`, process it with a no-op/identity chain, save the result to `render.wav`, and invoke `audiobench compare` on the pair.

For the reproducible end-to-end PASS/FAIL examples, see [`demo/README.md`](demo/README.md). Regenerate them from the repository root with `python scripts/create_demo.py`.
