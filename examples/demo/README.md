# AudioBench demo cases

This directory contains small, reproducible end-to-end examples generated by `python scripts/create_demo.py` from the repository root (after `python -m pip install -e ".[dev]"`).

- `reference_white_noise.wav`: deterministic broadband reference signal at 48 kHz, 0.5 s.
- `render_identical.wav`: byte-for-byte copy of the reference, used to demonstrate an exact PASS.
- `render_delayed_2_5ms.wav`: copy of the same signal shifted by 120 samples (2.5 ms at 48 kHz), used to demonstrate that latency and fidelity gates fail with the default thresholds.
- `pass_report.html` / `pass_report.json`: report and machine-readable result for the exact match.
- `delay_fail_report.html` / `delay_fail_report.json`: report and machine-readable result for the delayed signal.
- `demo_manifest.json`: sample batch test manifest combining multiple test cases with suite thresholds.
- `batch/summary.html` / `batch/summary.json`: aggregated batch dashboard and summary data.
- `batch/identical-render.html` / `batch/delayed-render.html`: per-test HTML reports generated by the batch run.

The delayed case is deliberately a synthetic regression fixture, not a real plugin benchmark. These reports demonstrate both single-pair and multi-case batch regression workflows.
